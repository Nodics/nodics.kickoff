# agora.telco

The `nodics.referenceDemo` ownership gate runs through nTooling project validation
and `npm run test:data-ownership`. All demo manifest sections require explicit
selection; setup and publication retain their normal owner approvals.

Agora Telco reference demo data/composition ONLY: product and content
catalogs, branding, optional sample identities/accounts/assignments and explicit
composition selections. Reusable behavior and access definitions belong to their
existing implementing framework or accelerator owners. Profile owns standard
bootstrap users/access mechanics and runtime assignments; modules contribute
permissions. Genuine partner projects retain supported customization.

Axis uses business area + No access / View / Edit / Full control + Scope.
Full control does not bypass approval, ledger, simulation or tenant boundaries.
The authorized refactor has no backwards compatibility and introduces no parallel
authority. Preserve historical evidence and installed receipts; documentation and
business releases remain separate, explicitly governed selections. See
[AGENTS.md](AGENTS.md) and the resolved framework's nSetup customer contract.

## Sample data ownership

The content pack contains Telco media and merchandising, with shared
commerce/rendering contracts retained. Active release roots and versions come
from `data/manifest.json`. All retained content roots are checked for foreign
assets, orphan files and missing page/media references by
`npm run test:data-ownership` at the Kickoff root.

See [data ownership](llm/contracts/data-ownership-contract.md) for cleanup,
publication and previously imported runtime-record boundaries.


This module explicitly participates in Application Builder through
`nodics.applicationBuilder.dataPack: true` in its package metadata. The owning
customer project declares frontend, domain and preset choices. Preserve the
module's existing import-manifest and content ownership rules; Builder metadata
does not import, publish or validate this module's live data.

# Circa application contracts

Circa is the application identity over the eWaste domain accelerator. There is
no Circa-named framework accelerator. Reusable journey orchestration lives in
eWaste; this customer module owns application/site composition and deployment
choices. The frontend is the separate nodics.circa.eWaste application.

These requirements describe desired capability; individual backlog entries do
not certify implementation. The customer journey guide records acceptance and
remaining production gates. Preserve framework ownership and configurable
policy when implementing these requirements.

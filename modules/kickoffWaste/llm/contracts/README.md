# Kickoff Waste Contracts

This module is the real Kickoff example of the partner-project Waste overlay contract.

- Extend `eWaste` through project-owned data releases.
- Target `nodics.waste` schema names in import headers.
- Use code-keyed `saveAll` imports so overrides are intentional and idempotent.
- Keep reward, coupon, map, vendor, recycler, logistics, tenant, and enterprise responsibilities outside Waste records.

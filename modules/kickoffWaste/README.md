# Kickoff Waste

Kickoff Waste is a project-owned overlay for the Nodics Waste Management accelerator.

It demonstrates the partner customization layer in the standard flow:

1. `nodics.waste` owns reusable schemas, APIs, lifecycle services, and data-contribution policy.
2. `waste` and `eWaste` provide reusable accelerator packaging and initial electronic-waste reference data.
3. `kickoffWaste` contributes project-owned Waste data that extends or overrides accelerator presets.

The module intentionally owns data and examples only. Loyalty, coupon, location/provider, recycler, logistics, and vendor integrations belong in their owning project modules and may reference Waste records by code or source reference.
